# CT 해부학 탐색기 · KHSIM

실제 복부 CT 한 건으로 만든 3D 장기와 축상면·관상면·시상면을 십자선 하나로 함께 보는 학습 도구입니다.

**https://dragonmin070102-coder.github.io/ct-explorer/**

> 학습용입니다. 의료기기가 아니며 진단에 사용하지 마세요.
> For learning only. Not a medical device and not for diagnosis.

This repository holds only the built static site (GitHub Pages).

CT data: TotalSegmentator dataset (small subset v2.0.1) — Jakob Wasserthal, University Hospital Basel. https://doi.org/10.5281/zenodo.10047263 — licensed under CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). Modified: one case cropped, resampled, windowed and converted to 3D meshes; synthetic teaching lesions can be added. Full credits: credits/ and THIRD_PARTY_NOTICES.txt.

MRI data: TCIA TCGA-LIHC (Version 5), Erickson BJ et al., https://doi.org/10.7937/K9/TCIA.2016.IMMQW8UQ — CC BY 3.0. Based in part upon data generated by the TCGA Research Network (https://www.cancer.gov/tcga). Organ masks generated with TotalSegmentator total_mr (Apache-2.0). TCIA Data Usage Policy applies (no re-identification).
